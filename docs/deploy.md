# Развёртывание APEX на сервере (VPS)

Пошагово, без навыков программирования. Всё сводится к нескольким командам.

## Что нужно

- Сервер (VPS) с Ubuntu 22.04/24.04 и публичным IP (хватит 2 ГБ RAM).
- Домен, у которого A-запись указывает на IP сервера (см. [00-setup-overview.md](00-setup-overview.md)).
- Доступ к серверу по SSH.

## Шаг 1. Загрузить проект на сервер

Вариант А (через git, если проект в репозитории):
```bash
git clone <адрес-репозитория> apex && cd apex
```
Вариант Б: скопировать папку проекта на сервер (например, через scp).

## Шаг 2. Установить Docker (один раз)

```bash
sudo bash scripts/install-docker.sh
```

## Шаг 3. Создать и заполнить .env

```bash
cp .env.example .env
docker compose run --rm app npm run keygen
```
Команда `keygen` напечатает три строки с секретными ключами — вставьте их в `.env`
(`TOKEN_ENCRYPTION_KEY`, `SESSION_SECRET`, `MAGIC_LINK_SECRET`).

Затем откройте `.env` в редакторе (`nano .env`) и заполните:
- `APP_URL` и `APP_DOMAIN` — ваш домен;
- `OWNER_EMAIL` — ваш email (станет владельцем);
- `SMTP_*` — данные почты для отправки ссылок входа (можно позже; без них ссылки
  печатаются в логах);
- ключи площадок (`META_*`, `GOOGLE_*`, `TIKTOK_*`) — по мере готовности чек-листов.

> ⚠️ `TOKEN_ENCRYPTION_KEY` нельзя терять и менять после подключения аккаунтов.

## Шаг 4. Запустить

```bash
bash scripts/deploy.sh
```
Скрипт проверит настройки, соберёт и запустит всё. Caddy сам получит HTTPS-сертификат
для вашего домена. Через минуту откройте `https://ваш-домен`.

Проверьте, что работают страницы для регистрации приложений площадок:
`https://ваш-домен/privacy` и `https://ваш-домен/terms`.

## Повседневное обслуживание

- **Логи:** `docker compose logs -f app` (и `... worker`).
- **Перезапуск:** `docker compose restart app worker`.
- **Обновить версию:** `bash scripts/update.sh` (сам делает бэкап перед обновлением).
- **Бэкап:** `bash scripts/backup.sh` — база, медиа и `.env` попадут в папку `backups/`.
  Копируйте бэкапы на другой носитель/в облако.
- **Автобэкап раз в сутки:** `crontab -e`, добавить строку, которую печатает `backup.sh`.
- **Восстановление:** `bash scripts/restore.sh backups/db-….sql.gz`.

## Приглашение друзей

1. Войдите сами (ваш `OWNER_EMAIL`).
2. Откройте раздел **Инвайты** и создайте код (можно привязать к email друга и задать
   срок). Передайте код другу.
3. Друг открывает `https://ваш-домен/login`, вводит email и инвайт-код, получает
   ссылку входа, затем подключает свои соцсети.

> Напоминание: чтобы публикация у друзей работала без долгого ревью, добавьте их как
> тестеров в приложениях Meta/Google/TikTok (см. чек-листы).

# Настройка APX — общий порядок

Этот файл — карта. Делайте по шагам, не спеша. Технических знаний не требуется,
но понадобится терпение: площадки проверяют приложения, и это занимает время.

## Шаг 1. Что приготовить заранее

- **Домен** (например `apex.ваш-домен.ru`) — покупается у любого регистратора (~10–15 $/год).
- **Сервер (VPS)** с публичным IP — подойдёт самый дешёвый (2 ГБ RAM). Провайдеры:
  Hetzner, Timeweb, DigitalOcean и др. На него позже установим приложение.
- **Почтовый ящик** для технических писем (вход друзей по ссылке).

> Пока сервер не куплен, можно всё протестировать локально на своём компьютере
> (адрес `http://localhost:3000`). Но для реальной работы площадкам нужен домен с https.

## Шаг 2. Привязать домен к серверу

В панели регистратора домена создайте **A-запись**, указывающую на IP вашего сервера.
Через некоторое время `ваш-домен` начнёт открывать сервер.

## Шаг 3. Разместить Privacy Policy и Terms

Площадки требуют ссылки на «Политику конфиденциальности» и «Условия». Готовые заготовки
лежат рядом: [privacy-template.md](privacy-template.md) и [terms-template.md](terms-template.md).
Их нужно будет открыть по адресам вида `https://ваш-домен/privacy` и `/terms`
(приложение само их отдаст — настроим на этапе разработки).

## Шаг 4. Зарегистрировать приложения площадок

Делайте по одному. Каждый чек-лист даёт вам пару «ключ + секрет», которые вы впишете в `.env`.

1. [setup-meta.md](setup-meta.md) — Facebook + Instagram (два в одном приложении Meta).
2. [setup-google-youtube.md](setup-google-youtube.md) — YouTube.
3. [setup-tiktok.md](setup-tiktok.md) — TikTok.

> Можно начинать с любой площадки. Что настроено — то и заработает; остальные подключите позже.

## Шаг 5. Заполнить .env и запустить

1. Скопируйте `.env.example` в `.env`.
2. Выполните генерацию секретных ключей и впишите их в `.env`.
3. Впишите ключи площадок из шага 4.
4. Запустите приложение (одна команда — инструкция появится в README по мере готовности).

## Важно про «реальные» ограничения

- **Для друзей всё работает почти сразу**, если добавить их как «тестеров» в приложении Meta
  и в Google/TikTok (режим разработки). Это нормальный и безопасный способ для узкого круга.
- **Чтобы открыть доступ широкой публике** (незнакомым людям), нужны проверки:
  бизнес-верификация Meta, верификация Google, аудит TikTok. Это недели ожидания — но для
  вас и друзей это НЕ требуется на старте.

## Безопасность — коротко

- Файл `.env` с ключами — как связка ключей от всех аккаунтов. Никогда никому не пересылайте,
  не публикуйте, не кладите в облако в открытом виде.
- Токены друзей хранятся в базе в зашифрованном виде.
- Вход — по одноразовой ссылке на email, паролей нет.

# Настройка TikTok

Результат — два значения для `.env`: `TIKTOK_CLIENT_KEY` и `TIKTOK_CLIENT_SECRET`.

> Самое честное предупреждение: у TikTok самая строгая процедура. До прохождения
> **аудита приложения** автопубликация работает в ограниченном режиме — видео уходят
> **в черновики / как приватные**, с суточными лимитами. Публичная автопубликация —
> только после аудита (обычно недели ожидания). Поэтому на старте APX грузит
> видео в черновик TikTok, а вы публикуете его вручную одним нажатием в приложении.

## Шаги

1. Откройте **https://developers.tiktok.com/** и войдите. Примите условия.
2. **Manage apps → Connect an app** (создать приложение). Введите название, описание, иконку.
3. Укажите домен и ссылки на **Privacy Policy** (`https://ваш-домен/privacy`) и **Terms**.
4. Добавьте продукты:
   - **Login Kit** — вход через TikTok.
   - **Content Posting API** — публикация видео.
5. Запросите scopes (разрешения):
   - `user.info.basic`
   - `video.upload` — загрузка в черновик (работает без аудита).
   - `video.publish` — прямая публикация (откроется после аудита).
6. В настройках входа добавьте **Redirect URI**:
   ```
   https://ваш-домен/api/connect/tiktok/callback
   ```
7. На странице приложения скопируйте **Client key** → `TIKTOK_CLIENT_KEY`
   и **Client secret** → `TIKTOK_CLIENT_SECRET`. Впишите в `.env`.
8. **Verify URL / доменная проверка.** TikTok попросит подтвердить владение доменом
   (загрузить файл-подтверждение или добавить запись). Следуйте инструкции на их сайте —
   приложение умеет отдавать файл проверки по нужному адресу.

## Режимы

- **Сейчас (без аудита):** `video.upload` → видео появляется в разделе черновиков вашего
  TikTok; публикуете вручную. Безопасно и достаточно для начала.
- **После аудита:** `video.publish` → прямая публикация из APX. Для аудита нужно
  показать на видео, что интерфейс соответствует требованиям TikTok (экраны согласия,
  выбор приватности, пометка рекламного контента).

## Итог

В `.env`:
```
TIKTOK_CLIENT_KEY=...
TIKTOK_CLIENT_SECRET=...
```
И добавлен redirect `https://ваш-домен/api/connect/tiktok/callback`, пройдена доменная проверка.

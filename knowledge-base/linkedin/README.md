# LinkedIn — база знаний

Активный канал №1. Сюда складывается **всё** по LinkedIn.

## Структура папки

| Папка | Что внутри |
|-------|------------|
| `strategy/` | Позиционирование, ЦА, рубрикатор, цели и метрики, контент-план |
| `content/` | Готовые и черновые посты, заголовки, хуки, шаблоны |
| `assets/` | Картинки, карусели, видео, обложки, шаблоны оформления |
| `research/` | Конкуренты, референсы, инсайты, выдержки из исследований, тренды |
| `logs/` | Журнал публикаций и результатов (охваты, реакции, лиды) |

## Рабочие правила

1. Один документ = одна тема. Имя файла — `kebab-case.md`.
2. Даты в именах и текстах — абсолютные: `2026-10-18`.
3. Каждый опубликованный пост фиксируется в `logs/publications.md`.
4. Черновики живут в `content/drafts/`, опубликованное переносится в `content/published/`.
5. Любая новая договорённость по каналу — сразу в `strategy/`, а не в переписке.
